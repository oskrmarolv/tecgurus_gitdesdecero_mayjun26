# GIT: Notes

> Anotaciones y explicaciones importantes

## git-merge

merge fast-forward 
  - genera un commit especial de tipo "merge"
  - mantiene el historico de cambios 

merge squash
  - genera 1 solo commit que empaqueta todo el historico de cambios
  - se pierde el historico de cambios
  - empaquetado en el historico: envian cambios a "main".
  - procesos de rollback facilmente
